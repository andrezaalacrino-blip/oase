# Página CPA 2026 — Faculdade OASE

Site estático pronto para hospedagem na Vercel.

## Arquivos
- `index.html`
- `logo-oase.png`

## Publicação
Envie a pasta para um repositório GitHub e conecte na Vercel.

## Importante
Os dois botões de formulário foram deixados com `href="#"` porque os links da OASE ainda não foram informados.

Quando tiver os links oficiais, substitua no `index.html` os dois trechos:
- botão **Avaliação Geral**
- botão **Avaliação Docente**

Depois rode:

```bash
git add .
git commit -m "CPA OASE - atualizar links dos formularios"
git push origin main
```

## Observação
O pop-up introdutório aparece em todo acesso ou atualização da página. Após fechar ou concluir, as duas avaliações ficam disponíveis até a próxima recarga.
